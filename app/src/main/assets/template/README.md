# Folder untuk template kwitansi

Letakkan **SATU** file berikut di folder ini:

**`kwitansi.jpg`** - Template kwitansi lengkap (WAJIB)

Template ini sudah harus mencakup seluruh elemen statis:
- Logo Hastaka
- Logo Pesona Indonesia
- Tanda tangan
- Bingkai, garis, dan elemen desain lainnya
- Tulisan atau informasi statis yang tercetak

**PENTING:**
- Gunakan file asli template yang Anda berikan, JANGAN mengganti dengan hasil generate AI
- **TIDAK PERLU** file logo atau tanda tangan terpisah - semua sudah ada di gambar template
- Nomor kwitansi mengikuti yang tercetak pada template (tetap sama untuk semua kwitansi)
- Aplikasi hanya menambahkan: Nama Siswa, Nominal, dan Keterangan Pembayaran
- Jangan menghapus, memindahkan, atau menggambar ulang elemen yang sudah ada di template
- Pertahankan proporsi dan kualitas asli gambar
- Format file: JPG/JPEG
